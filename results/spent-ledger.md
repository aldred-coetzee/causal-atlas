# What has been read against what

Like the seed ledger, for real records. A real outcome that has been scored against a driver over some years cannot test that driver on those years again: anything further is a check, a description or labelled development. This file is the one place that says which is which. It is updated in the same commit as any read of a real record, and consulted before any rule that names a real outcome.

Started 2026-11-10 from the results files. "Read" means scored on years held back, once, under a rule committed first. "Fitted" means used to build or tune a method. Where this file and a results file disagree, the results file is right and this file is corrected.

## What this means for a search across many series

- A pair in this table marked spent may be among a finder's proposals only as a known answer, said to be one, and never as a new result.
- An outcome read against one driver is not spent for another, but it is not untouched either: this session has seen how its later years behave (which baselines failed, which years were odd). A rule for such an outcome says so, and prefers years or records never scored where there are any.
- The years a finder may see and the years the referee keeps are fixed for every outcome before a finder runs, and written here.
- Series brought into the one table and described alone (lengths, gaps, memory) are not read against anything, and are not entered here.
