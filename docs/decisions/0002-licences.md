# 0002: MIT for code, CC BY 4.0 for text

**Date:** 2026-11-05. **Status:** accepted.

## Context

The owner's brief asks for both licence files in the root commit, matching an
earlier project of his, unless he says otherwise. He has not.

## Decision

Code is MIT (`LICENSE`), copyright 2026 Aldred Coetzee. Text is CC BY 4.0
(`LICENSE-CC-BY-4.0`, the unmodified legal code). Third-party text is quoted
briefly, attributed, and keeps its owner's licence.

## Consequences

Each dataset's licence is checked before use (rule 4) and recorded in the
manifest (rule 10). Results files hold statistics; a source's terms decide
whether even those need a note of attribution.
