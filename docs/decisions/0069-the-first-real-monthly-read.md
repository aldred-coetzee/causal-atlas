# 0069: The first read of the real table by month, and what is kept unopened

Status: accepted, 2026-11-12. Made by this session under decision 0040; reported to the owner, his to overrule.

## Context

The monthly read was counted on made-up tables with a lead defined as a pass not labelled as moving together, and every mark held (`results/monthly-lead-count.md`, decision 0068). The real monthly series of the one table have never been set beside each other. Every choice of panel, split and set could favour a result, so each is fixed here before any run.

## Decision

1. **The real monthly table is read once** under `results/stage-d-monthly-read.md`, committed before any run.
2. **The split:** finders see 1980 to 2008, the referee scores 2009 to 2019, and 2020 to 2024 are opened only for a row that passed, once. A later split would leave too few scored months for the monthly settings (120); an earlier one would lose the series that start in 2000. The cost is said in the rule: protests and burned area end before 2020 can confirm them and are left for a later rule.
3. **The panel is built by a count rule,** with no series or place chosen by hand. A place needs half the place-varying series (not a third), because five nought-filled series would otherwise keep every territory.
4. **Sets are by source,** chosen so that every tie in `docs/tied-series.md` between monthly series lies inside one set.
5. **Months with no row in the conflict events record are nought** from 1989, on the source's stated worldwide coverage.
6. **The member that tries every pair is left out,** as in the yearly reads, **and so is the member that reads a sign by a common series' state**, which with 92 common series ran a made-up rehearsal out of memory. The counted read had both; the planted runs on this table measure the read as made.
7. **Placebos move time by whole years** so the season stays in place, and count leads, not passes, as the made-up count did. Passes labelled as moving together are reported apart.
8. **A lead on drought, storms or earthquakes is a false lead by physics** and is counted as one, a check the yearly reads did not have.
9. **An independent reader reads rule and code before the first run.**

## Considered and not done

- **Reading changes by month**, as the second yearly read did. The monthly count was made on levels with the season out and heard small links; a change read by month is uncounted.
- **Keeping the every-pair member.** 106 series by 202 places by 348 months; not tried on the real table, to keep the rule fixed before any run.
- **A split that keeps protests and fire.** It would leave them unconfirmable or shorten the scored stretch below the counted setting.
- **Planting links from common series.** Stage B's sizing is by place; a common input would need its own sizing, uncounted.

## Consequences

2009 to 2019 of the monthly panel will have been read once, with rearranged forms seen 40 times. The spent ledger takes its rows with the runs.
