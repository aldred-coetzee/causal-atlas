## This session's reading

1. **Tests of one driver against one outcome are a means, not the project.** Since decision 0046 every iteration has set one named driver against one outcome. That was done to get a forecast test that can be trusted; it has drifted from the aim he gave in decisions 0021 and 0027 and gives again here.
2. **The test now running is finished as registered** (decision 0054): its rule is committed, its made-up records are nearly all run, and what it tests, using a link only in the records where it has shown itself before, is a piece any search across many series needs.
3. **After it, the work is the two things he names.** (a) The search: many series tried against many outcomes, with controls that stay honest at that scale, proved on made-up records before any real one. What has held up so far is kept as its parts: the score is forecast error out of time against the baseline, the controls are other years' values, a link is used only where it has shown itself. (b) The data: each data set brought to one shape of place, month, series and value, entered in the manifest at first fetch, so that the next one is cheap to add and any two can be set side by side.
4. **The not-now list.** The brief puts "more domains", "a generic adapter framework" and "a dataset catalogue" under not now, each needing a Phase 1 result and his yes. Results exist. His words are read as the yes for more data sets and for one shape to hold them, as far as the next iteration needs; not for global coverage, maps, an API, a web UI or a literature survey, which he did not mention. Rule 6 says that when he says to go broader the rule is quoted back and he is asked to confirm. He has said "Do not ask me" (decision 0040), so the rule is quoted in the report to him as information, as it was then.

## Not relaxed

Rule 1 (experiment before survey), rule 2 (beat the baseline out of time), rule 3 (made-up records with planted links first, generator sharing nothing with the detector), rule 4 (a data set is confirmed fetchable and licensed before anything is designed around it), rule 5 (reading pulled by a decision), rule 9 (the rule committed before any counted number, the held-out record scored once) and rule 10 (hygiene at entry). "Unexpected" is not a licence to report what a search throws up: a link nobody expected has to clear the same bar as one everybody knew, and a search over many pairs has to say how many it would name by chance.
