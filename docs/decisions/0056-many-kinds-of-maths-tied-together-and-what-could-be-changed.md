## This session's reading of what he adds

1. **More than one kind of mathematics.** Everything run so far hears one kind of link: a steady, straight-line, lagged one. A link that shows only in extremes, only above a threshold, only when two things coincide, or that changes sign with the state of the system, is silent to it. The search needs finders of different kinds.
2. **Tied together.** One way to tie them, proposed and not yet tested: every finder, whatever its mathematics, puts out candidates in one form (which series, which outcome, where, how far ahead, under what condition, and a rule for using it in a forecast), and every candidate goes before the same referee, the one already proved on real data: does a forecast that uses it beat the baseline on years it has not seen, against other-years controls, and how many candidates would have passed by chance. The finders may be as inventive as they like because none of them is believed; only the referee is.
3. **Combinations.** Confirmed links are then brought together to forecast an event; a combination is a candidate like any other and passes the same referee.
4. **"What factors should we change".** This is a different question from prediction and the data cannot answer it alone (said in decision 0027 and unchanged): a link that forecasts well need not be one where changing the factor changes the outcome. It needs its own layer: links that hold across many places and periods, cases where the factor did change for outside reasons, and known mechanisms. Every result says which kind it is.
5. **The swarm.** Noted, nothing done. The shape fits (many small finders writing to one shared record, one referee), and a fixed constraint of this project stands in the way of using it at runtime as that project now describes itself: pipeline code here makes no model calls. Coordination, when there is something to coordinate, goes through next-pattern.

## First sketch of the kinds, to be tested and not assumed

Steady lagged links (what exists). Links of any shape (information measures, distance and kernel dependence). State-dependent links (empirical dynamic modelling). Links in extremes and between events (coincidence of events, tail dependence, self- and cross-exciting event models). Interactions and thresholds (tree ensembles, rule and subgroup search). Hidden shared modes across many series (factor and tensor decompositions, regimes). Warning signs with no named driver (rising variance and memory before a shift). Structure of the web of links itself (communities, hubs). For "what to change": invariance across places and periods, and natural experiments.

**How the kinds are chosen: by measurement, not by reading (rules 1 and 3).** Made-up records with planted links of different kinds (steady, threshold, extremes only, two drivers together, sign that flips, a hidden shared mode, and none), each finder run on each, and a table of which hears which and how often each cries wolf. The limits already measured carry over: with records of forty to five hundred points only strong links are heard, and more data sets multiply the pairs tried without lengthening any record, so counting what chance would name is the centre of the mathematics, not an afterthought.
