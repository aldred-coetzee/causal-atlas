# 0001: A public GitHub repo, not a private Codeberg one

**Date:** 2026-11-05. **Status:** accepted.

## Context

The owner's October plan was a new private repo on Codeberg. An older repo of
this name on GitHub held unrelated history.

## Decision

The project lives at `github.com/aldred-coetzee/causal-atlas`, public. The owner
deleted the old repo and recreated it empty on 2026-11-05, so there is no old
content and no old history. The first commit is the root commit on `main`, with
no trailer. Never force-push. This supersedes the October plan.

## Consequences

History is permanent and public, so there is no later clean-up pass: everything
is written to be read, and hygiene happens at entry. The owner's verbatim brief
and box configuration stay in a private repo; this repo holds a distillation.
GitHub is not European infrastructure; this is the owner's stated choice and
overrides the "where practical" preference in decision 0003 for this one item.
